⛅ Weather Forecaster
A simple and interactive web app that displays real-time weather information for any city using live data from a weather API. Built for users to quickly check current temperature, conditions, and more.
# Author- Vicky Kuthe (Web developer)
🌟 Features
-Search weather by city name
-Displays temperature, humidity, wind speed, and weather conditions
-Clean and responsive UI
-Real-time data fetched from OpenWeatherMap API (or other)

🛠️ Tech Stack
-HTML
-CSS
-JavaScript
-Weather API (e.g., OpenWeatherMap)

🚀 How to Run
-Clone the repository:
git clone https://github.com/vickykuthe/Weather-Forecaster.git

-Open the index.html file in your browser
(If using API key, add it in the script where indicated)
